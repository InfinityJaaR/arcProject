## ?? Algoritmo de Dijkstra (Simplificado)

```
Input: startNode, endNode

???????????????????????????????????????????????
?  1. Inicializar                              ?
?     distances[all] = ?                       ?
?     distances[startNode] = 0                 ?
?     unvisited = {todos los nodos}            ?
???????????????????????????????????????????????
         ?
         ?
???????????????????????????????????????????????
?  2. While unvisited no está vacío           ?
?                                              ?
?     2.1 Encontrar nodo con menor distancia  ?
?         current = nodo con min(distances)    ?
?                                              ?
?     2.2 Si current == endNode ? TERMINADO  ?
?                                              ?
?     2.3 Marcar current como visitado        ?
?         unvisited.remove(current)            ?
?                                              ?
?     2.4 Para cada vecino no visitado:       ?
?         newDist = distances[current] +       ?
?                   edge.distance              ?
?                                              ?
?         Si newDist < distances[vecino]:      ?
?            distances[vecino] = newDist       ?
?            previous[vecino] = current        ?
???????????????????????????????????????????????
         ?
         ?
???????????????????????????????????????????????
?  3. Reconstruir camino                       ?
?     path = []                                ?
?     current = endNode                        ?
?                                              ?
?     While current != null:                   ?
?       path.insert(0, current)                ?
?       current = previous[current]            ?
?                                              ?
?     Return path                              ?
????????????????????????????????????????????????
```

## ?? Ejemplo Paso a Paso de Dijkstra

Grafo:
```
     A
     ? 50
     B
   /   \
 80     40
 /       \
C         D
          ? 60
          E
```

Encontrar camino de A a E:

### Iteración 1:
```
current = A
distances: A=0, B=?, C=?, D=?, E=?

Vecinos de A: {B}
  distances[B] = 0 + 50 = 50 ?
  
distances: A=0, B=50, C=?, D=?, E=?
previous: B?A
```

### Iteración 2:
```
current = B (menor distancia no visitado)
distances: A=0, B=50, C=?, D=?, E=?

Vecinos de B: {A (visitado), C, D}
  distances[C] = 50 + 80 = 130 ?
  distances[D] = 50 + 40 = 90 ?
  
distances: A=0, B=50, C=130, D=90, E=?
previous: B?A, C?B, D?B
```

### Iteración 3:
```
current = D (menor distancia no visitado)
distances: A=0, B=50, C=130, D=90, E=?

Vecinos de D: {B (visitado), E}
  distances[E] = 90 + 60 = 150 ?
  
distances: A=0, B=50, C=130, D=90, E=150
previous: B?A, C?B, D?B, E?D
```

### Iteración 4:
```
current = C
Ya llegamos a E en iteración anterior,
pero verificamos si C ofrece mejor camino a E
(no lo hace porque C no se conecta con E)
```

### Reconstruir Camino:
```
current = E
path = [E]

current = previous[E] = D
path = [D, E]

current = previous[D] = B
path = [B, D, E]

current = previous[B] = A
path = [A, B, D, E]

current = previous[A] = null
TERMINADO!

Camino final: A ? B ? D ? E
Distancia total: 150m
```
