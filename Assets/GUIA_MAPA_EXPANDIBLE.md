# ??? GUÍA COMPLETA: MAPA EXPANDIBLE

## ?? ¿Qué es el Mapa Expandible?

El **Mapa Expandible** es una mejora del minimapa que permite:

### Vista Compacta (Minimapa Normal)
- ?? Pequeño panel en la esquina superior derecha
- ??? Visión general rápida durante navegación
- ?? Botón para expandir a pantalla completa

### Vista Expandida (Mapa Grande)
- ?? Pantalla completa para ver detalles
- ?? Zoom in/out (0.5x - 3.0x)
- ?? Pan/arrastre con el dedo
- ?? Botón para centrar en tu ubicación
- ? Botón para volver a vista compacta

## ?? INTEGRACIÓN CON CÓDIGO

### Expandir/Colapsar desde Código

```csharp
// Obtener referencia
ExpandableMapController mapController = FindObjectOfType<ExpandableMapController>();

// Expandir
mapController.ExpandMap();

// Colapsar
mapController.CollapseMap();

// Toggle
mapController.ToggleExpanded();
```

### Centrar Programáticamente

```csharp
mapController.CenterOnUserLocation();
```

### Verificar Estado

```csharp
// No hay propiedad pública, pero puedes verificar si el panel está activo
bool isExpanded = mapController.expandedMapPanel.activeSelf;
```

## ?? SOLUCIÓN DE PROBLEMAS

### Problema: Botón expandir no aparece
**Solución:**
```
1. Unity ? AR Navigation ? Setup Expandable Map System
2. Click "?? Verificar Configuración Actual"
3. Si falta el botón, ejecuta "Configurar Automáticamente"
```

### Problema: Mapa expandido está en blanco
**Causa:** El `mapContainer` no se movió correctamente

**Solución:**
```csharp
// Verificar en MiniMapController que mapContainer esté asignado
// Debería moverse automáticamente entre contenedores
```

### Problema: Zoom no funciona
**Solución:**
```
1. Verifica que zoomSlider esté asignado en Inspector
2. Verifica que minZoom < maxZoom
3. Revisa logs para errores
```

### Problema: No puedo arrastrar el mapa
**Solución:**
```
1. Verifica que Allow Panning esté ? activado
2. Verifica que estés en vista expandida
3. Intenta con un solo dedo (no multi-touch)
```

### Problema: Animación es brusca
**Solución:**
```
1. Aumenta Transition Duration (ej: 0.5)
2. Ajusta Transition Curve en Inspector
3. Verifica que CanvasGroups estén presentes
```

## ?? COMPARACIÓN: Minimapa vs Expandible

| Característica | Minimapa Normal | Mapa Expandible |
|----------------|-----------------|-----------------|
| Tamaño | 260x260 px | ~90% pantalla |
| Zoom | Fijo (1.0x) | 0.5x - 3.0x |
| Pan | No | Sí (arrastre) |
| Detalles | Limitados | Alta visibilidad |
| Uso durante navegación | ? Ideal | ?? Temporal |
| Planificación de ruta | ? Difícil | ? Excelente |
| Obstrucción de AR | ? Mínima | ?? Total (temporal) |

### Casos de Uso Recomendados

**Usa Minimapa Compacto cuando:**
- ? Estás navegando activamente
- ? Necesitas ver la cámara AR
- ? Solo quieres referencia rápida

**Usa Mapa Expandido cuando:**
- ? Quieres planificar tu ruta antes de empezar
- ? Necesitas ver todo el campus de un vistazo
- ? Quieres explorar rutas alternativas
- ? Necesitas ver detalles de edificios específicos
