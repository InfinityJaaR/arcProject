## ?? Cómo Encontrar Tus Bounds Correctos

### Método 1: Usar los Logs (Recomendado)
1. Activa `Use Auto Bounds = true` temporalmente
2. Ejecuta la app
3. Busca en los logs:
   ```
   [MiniMapController] ?? Primeros nodos:
      - Edificio D  (13.720701, -89.200618)
      - Nodo N      (13.720225, -89.200383)
      - Arquitectura (13.720900, -89.200424)
   ```
4. Anota las coordenadas de varios nodos conocidos
5. Calcula bounds aproximados:
   ```
   Min Lat = Menor latitud  - 0.0005
   Max Lat = Mayor latitud  + 0.0005
   Min Lon = Menor longitud - 0.0005
   Max Lon = Mayor longitud + 0.0005
   ```

### Método 2: Usar Google Maps
1. Abre Google Maps
2. Busca tu campus
3. Click derecho en esquina inferior-izquierda ? "¿Qué hay aquí?"
4. Anota las coordenadas (lat, lon)
5. Repite para esquina superior-derecha
6. Usa esas coordenadas como bounds

### Método 3: Usar Firebase Console
1. Abre Firebase ? Firestore
2. Ve a `buildingLocations`
3. Revisa manualmente las coordenadas de varios edificios conocidos
4. Calcula el rango mínimo-máximo

## ?? Errores Comunes

### ? Bounds Muy Grandes
```
Síntoma: Map size muy grande en logs (>10km)
Causa: Nodos outliers incluidos en cálculo
Solución: Usar bounds manuales
```

### ? Minimapa Vacío
```
Síntoma: 0 nodos dentro de bounds
Causa: Bounds incorrectos que excluyen todos los nodos
Solución: Verificar que bounds contengan tus nodos
```

### ? Nodos Cortados
```
Síntoma: Algunos nodos no se ven
Causa: Bounds muy ajustados
Solución: Agregar margen de 0.0005-0.001 grados
```

### ? Mapa Distorsionado
```
Síntoma: Círculos se ven como óvalos
Causa: Aspect ratio incorrecto (ya corregido en código)
Solución: Usar la nueva versión de MiniMapController
```
